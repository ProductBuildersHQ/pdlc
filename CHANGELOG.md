## [v0.2.0] - 2026-08-15 ([`d6342a0`](https://github.com/ProductBuildersHQ/pdlc/commit/d6342a0))

### Highlights

- The six-stage PDLC model (Product Definition, Builder Definition, Implementation, Deployment, Builder Operations, Product Operations) is now re-exported as a first-class Go API, backed by the canonical catalog entry in productbuildershq-frameworks v0.3.0

### Added

- `Stage` type (re-exporting `frameworks.PDLCPhase`) and `Stages()`/`MustStages()`/`StageByID()` functions, plus six canonical `StageXxx` ID constants (`StageProductDefinition` through `StageProductOperations`), so downstream consumers depend on `pdlc` rather than importing the catalog module directly ([`0db9f6c`](https://github.com/ProductBuildersHQ/pdlc/commit/0db9f6c))

### Fixed

- `docs/specification/lifecycle.md`'s link to `stages.go` used a relative path outside the `docs/` tree, which failed `mkdocs build --strict`; now an absolute GitHub blob URL ([`7bd7f68`](https://github.com/ProductBuildersHQ/pdlc/commit/7bd7f68))

### Dependencies

- Bump `github.com/plexusone/structured-evaluation` from v0.10.0 to v0.13.0 ([`4e5fd5e`](https://github.com/ProductBuildersHQ/pdlc/commit/4e5fd5e))
- Add `github.com/ProductBuildersHQ/productbuildershq-frameworks` v0.3.0 ([`0db9f6c`](https://github.com/ProductBuildersHQ/pdlc/commit/0db9f6c))

### Documentation

- Rewrote `lifecycle.md` from the old two-lifecycle framing (Product Definition Lifecycle / Builder Lifecycle) to the full six-stage model; Product Definition's seven sub-stages remain normatively unchanged ([`d1b3398`](https://github.com/ProductBuildersHQ/pdlc/commit/d1b3398))
- Added a Go Module Usage section to README.md and docs/index.md documenting `Stages()`/`MustStages()`/`StageByID()` alongside the pre-existing `Layout()`/`MustLayout()`, and updated the productbuildershq-frameworks ecosystem-table row to reflect the new dependency/re-export relationship ([`d6342a0`](https://github.com/ProductBuildersHQ/pdlc/commit/d6342a0))

### Tests

- `TestStages`, `TestMustStages`, `TestStageByID`, `TestStageIDConstantsMatchCatalog` — stage order, canonical-catalog resolution, and every exported stage-ID constant resolving via `StageByID` ([`73d7e7b`](https://github.com/ProductBuildersHQ/pdlc/commit/73d7e7b))

## [v0.1.0] - 2026-07-20 ([`0abb1d3`](https://github.com/ProductBuildersHQ/pdlc/commit/0abb1d3))

### Highlights

- Initial release of the ProductBuildersHQ Product Development Lifecycle (PDLC): the normative specification plus a Go module that classifies a project repository against the layout contract and evaluates readiness for handoff to a builder
- Readiness evaluation emits a structured-evaluation report scoring each in-scope domain on artifact presence and, where a tool has run, quality — with unrun tools held at conditional rather than passing silently

### Added

- Layout contract as Go types with an embedded layout.yaml: canonical paths, per-profile requirement levels, authority, and detection heuristics for every product-definition artifact ([`b83e9eb`](https://github.com/ProductBuildersHQ/pdlc/commit/b83e9eb))
- Repository classifier that skips immovable (tool-native) and ignored (templates, examples, fixtures) directories, flags path conflicts, and never auto-proposes moves from content-only matches ([`b83e9eb`](https://github.com/ProductBuildersHQ/pdlc/commit/b83e9eb))
- pdlc.yaml project manifest with profile selection and per-domain override resolution ([`d66021b`](https://github.com/ProductBuildersHQ/pdlc/commit/d66021b))
- Readiness evaluator producing a structured-evaluation report: checklist-scale presence, leaf-report quality, and TOOL_NOT_RUN semantics for unrun tools ([`9694cf4`](https://github.com/ProductBuildersHQ/pdlc/commit/9694cf4))
- pdlc CLI (Cobra) with check, inventory, init, and layout commands ([`bdc8024`](https://github.com/ProductBuildersHQ/pdlc/commit/bdc8024))
- Go-first JSON Schema generation for the layout and project manifests, embedded for programmatic access ([`82ed0b0`](https://github.com/ProductBuildersHQ/pdlc/commit/82ed0b0))
- PDLC specification: lifecycle stages, canonical project layout, review-site assembly, quality evaluation, requirement registry and executable acceptance tests, agent-driven adoption, and the Product Baseline handoff contract ([`0abb1d3`](https://github.com/ProductBuildersHQ/pdlc/commit/0abb1d3))

### Dependencies

- Add github.com/plexusone/structured-evaluation for readiness report output ([`ebff482`](https://github.com/ProductBuildersHQ/pdlc/commit/ebff482))
- Add github.com/spf13/cobra for the CLI ([`ebff482`](https://github.com/ProductBuildersHQ/pdlc/commit/ebff482))
- Add github.com/invopop/jsonschema for Go-first schema generation ([`ebff482`](https://github.com/ProductBuildersHQ/pdlc/commit/ebff482))

### Tests

- Coverage for layout classification (immovable protection, misplaced-artifact detection, conflicts) and readiness evaluation (override semantics, TOOL_NOT_RUN, conditional readiness, locale coverage, profile scaling, idempotence) ([`727a721`](https://github.com/ProductBuildersHQ/pdlc/commit/727a721))
